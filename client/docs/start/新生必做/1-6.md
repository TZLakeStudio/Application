# 图书馆新生知识闭关

为保证同学们入校即开通借书权限, 请大家在入学前通过以下两种途径(选择其一)完成知识闯关:

## 1. 学习入口

1. **手机端**: 扫描二维码关注`湖南大学图书馆`微信公众号, 点击微信公众号`微服务大厅`菜单下的`新生闯关`菜单或发送`新生闯关`, 点击自动回复中的`新生闯关`链接, 按步骤完成.

    ![图书馆](/docs/start/新生必做/1-6-图书馆.png)

2. **电脑端**: 通过`图书馆主页` [https://lib.hnu.edu.cn](https://lib.hnu.edu.cn) 登录`新生知识闯关`平台, 按步骤完成.

## 2. 注意事项

- 账号为**身份证号码**或**来往大陆通行证号码(港澳台学生)**, 无需输入密码, 点击`用户登录`, 即可进入闯关系统. 闯关完成后, 借书权限自动开通. 
- `2025年7-8月`, 图书馆微信公众号将不定期推送`新生知识闯关微文`, 请及时关注. 如需咨询, 请加`QQ群`: **839046202**.
