# 校园卡校园网使用说明

## 1. 校园卡

1. 校园卡在新生报到时放入`新生大礼包`中发放, 校园卡查询, 消费`初始密码`为**身份证后六位数字**.  

2. 校园卡充值:

    - 现金充值:

        `自助办理`: 现金充值机设置在`南校区三食堂`, `天马二食堂`, `财院校区食堂`.

        `人工办理`: 各食堂人工充值窗口均可办理.

    - 线上充值: 通过`湖南大学微信公众号`或`湖南大学计划财务处微信公众号`的`校园缴费`服务进行充值.
  
3. 学生个人门户[portal.hnu.edu.cn](http://portal.hnu.edu.cn)已自动开通, `账号`为**本人学号**, `初始密码`为**身份证件(含护照, 台胞证等)号后六位 + 学号**(英文字母需大写), 请大家在首次登录后, 立即修改密码.

    _如提示密码错误可点击`忘记密码`, 通过`绑定手机号码`自助修改个人门户密码._

## 2. 校园网

1. 校园网账号不同于个人门户, 需同学们**自行开通**. 入校后可使用个人门户账号, 密码登录校园网. 

2. 登录个人门户进入`校园网业务`后, 可自助开通`电子邮箱`等校园网信息业务.

3. 每位同学每月享有**40G免费流量**. 
   
    - 当月流量使用**超过40G**时, 上网账号将被首次锁定, 可通过`个人门户`或`湖南大学微信企业号`查询校园网网络流量使用情况.
    - 每月超出40G流量的超额部分, 将产生费用, 次月缴纳(超额流量的资费为**0.5元/G, 30元/月封顶**). 通过`个人门户流量查询`, `湖南大学微信企业号`, `湖南大学信息化办`公众号均可完成缴费. 

## 3. 注意事项

1. 了解更多**校园卡, 校园网**等数字信息, 请扫描下方二维码关注`湖南大学信息化办`.

    ![湖南大学信息化办](/docs/start/新生必做/1-3-信息化办.png)

2. 扫描下方二维码, 用`个人门户`的账号和密码登录, 填入手机完成注册后, 会弹出学校微信企业号二维码, 长按二维码即可关注`湖南大学微信企业号`. 关注学校微信企业号后, 可实时接收通知消息, 该公众号具有**校园网流量、数字校园卡、一网通办线上办理业务**等服务功能, 未来将集成更多的信息化服务功能. 

    ![湖南大学微信企业号](/docs/start/新生必做/1-3-微信企业号.png)

3. 在校内, 如遇任何信息化问题, 可拨打`0731-88821520`咨询及报修.
