# 新生预报到

新生扫描二维码关注`湖大学工`微信公众号, 点击`菜单栏`/`联系我们`/`迎新系统`, 进入`湖南大学迎新系统`.

![湖大学工](/docs/start/新生必做/1-1-二维码.png)

`系统登录名`为**高考考生号**, `初始密码`为**身份证后六位**. 请在系统中完成信息填写, 进行预报到.

`湖南大学迎新系统`定于`8月10日`开通, 如有调整请以登录页面通知为准.

`湖南大学迎新系统`网址: [http://yxxt.hnu.edu.cn](http://yxxt.hnu.edu.cn)

请如实填报系统中的`个人信息`, `来校行程方式`等各项信息, 完成全部必填信息后将生成报到二维码.
