# 国防教育自主学习

`《军事技能》`课程(以下简称`军训`)是高校学生必修课程. 

按有关要求, 学校计划在`2025年10月13日 - 26日`组织本科新生集中参加军训. 

作为军训内容之一, 全体2025级新生须在入学前开展`基本军事知识学习和测试`, 测试成绩将作为军训成绩的一部分计入学籍档案.

请全体学生开学前进行自主学习.

1. 学习方式1: 扫描下方二维码, 关注`湖大学工`微信公众号, 点击底部导航栏`学工聚焦`/`国防教育`.
2. 学习方式2: 通过打开网页链接 [http://xgb.hnu.edu.cn/in­-fo/1025/9128.htm](http://xgb.hnu.edu.cn/in­-fo/1025/9128.htm) 进行学习.

测试时间段和测试方式将在开学报到前在学习内容页面更新.

:::info 注意

预科生不参加军训, 升入本科后再军训.

:::
