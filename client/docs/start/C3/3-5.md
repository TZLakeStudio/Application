# 大学生应征入伍宣传单

依法服兵役是中华人民共和国每一个公民义不容辞的责任和义务. 军营是一所培养人才的大学校, 是一座锻炼人才的大熔炉, 军旅生涯是一笔不可多得的财富. 参军报国既是磨砺人生, 实现理想抱负的重要途径, 更是热爱祖国的高尚行为!

## 1. 征集对象

- 身高：男生`160cm`以上，女生`158cm`以上.
- 体重: 体重符合下列条件且空腹血糖 $<7.0mmol/L$.
    - 男性: $17.5 \le BMI < 30$, 其中男性身体条件兵 $17.5 \le BMI < 27$.
    - 女性: $17 \le BMI < 24$

    _`BMI` = 体重(千克)除以身高(米)的平方_
- 视力: 任何一眼裸眼视力不低于`4.5`
    
    任何一眼裸眼视力低于`4.8`, 需进行矫正视力检查. 任何一眼矫正视力低于`4.8`或矫正度数超过`600度`, 不合格.
    
    屈光不正经准分子激光手术(不含有晶体眼人工晶体植入术等其他术式)后半年以上, 无并发症, 任何一眼裸眼视力达到`4.8`, 眼底检查正常, 除条件兵外合格.
- 年龄: 在校生不超过`22`周岁, 本科毕业生男性不超过`24`周岁, 女性不超过`22`周岁, 研究生不超过`26`周岁.

## 2. 政治要求

拥护中华人民共和国宪法, 拥护中国共产党领导和社会主义制度, 热爱国防和军队, 遵纪守法, 具有良好的政治素质和道德品行, 政考合格.

## 3. 全国征兵网

有意向的同学可登录`全国征兵网`进行网上预征报名

网址: [http://www.gfbzb.gov.cn](http://www.gfbzb.gov.cn)

## 4. 网上预征报名有哪些具体内容?

填写预征报名表并提交成功后, 正确填写并打印`《大学生预征对象登记表》`, `《应征入伍高校毕业生补偿学费代偿国家助学贷款申请表》`.

登录学信网后, 下载打印`《学籍在线证明(申请)表》`, 各`一式2份`.

1寸照片4张, 2寸2张(红底或蓝底免冠照). 交学校武装部征兵工作办公室备案.

## 5. 入伍程序

1. 登录`全国征兵网`进行预征报名.

    - 男性: 春征上年度`12月1日`至次年`2月10日`, 秋征上年度`12月1日`至`8月10`日.
    - 女性: 春征`1月1日`至`2月10日`, 秋征`7月1日`至`8月10日`.

2. 待审核通过后, 打印`《大学生预征对象登记表》`和`《大学生预征对象登记表存根》`交学校武装部征兵工作办公室.
3. 学校配合兵役机关组织`体检`, `政考`, 确定预征对象.
4. 两批兵员分别在`3月`和`8月`组织`复检`, `役前训练`, `谈话`, `审核定兵`, 在校生办理`休学手续`.
5. 
    - 春征: 3月中, 下旬到部队服役
    
    - 秋征: 9月上, 中旬左右到部队服役.

## 6. 激励政策

- 大学生优待政策:
    
    大学生参军入伍除享受义务兵正常优待外, 优先安排到军兵种或专业技术要求高的部队服役..

    在部队服役期间, 还可优先选改士官, 我校毕业生士兵还可直接选拔为军官, 在校生可在服役期间报考军校. 

    退役后, 在`就业安置`, `考研升学`等方面享受更多优惠政策.

- 保留入学资格:
    
    退役后可以在退役当年或者第2年复学, 高校新生持`《保留入学资格通知书》`和`高校录取通知书`, 学校办理入学手续.

- 学费资助:
    
    国家对应征入伍服义务兵役的高校学生在校期间缴纳的学费实行一次性补偿, 对获得的国家助学贷款实行代偿, 退役后复学或入学的实行学费减免(在校期间已免除全部学费的学生, 定向生除外).

    资助标准: 本专科生每人每年最高不超过`16000元`, 硕士研究生每人每年最高不超过`20000元`.

    在此基础上, 湖南大学对退役学生免收`住宿费`, 免收`国家学费资助标准与学生实际学费标准之间的差额`. 免收年限按照国家和学校对相应学历的修业年限据实计算(复学后攻读更高层次学历不在减免范围之内). 

    贫困的入伍学生复学后可优先申请困难资助.

- 奖励金:

    从湖南大学入伍, 长沙市一次性奖励`15000元`, 家庭优待金每户每年`25000元`. 进入新疆, 西藏地区服役的义务兵家庭, 长沙市给予一次性奖励金`20000元`.

    在此基础上, 湖南大学设立`国防奖学金`, 奖励应征入伍的学生, 奖励金额为`每人20000元`, 服役满两年时一次性发放.

- 课程修读与转专业:

    正常退役复学的学生, 可免修包括`体育课`, `军事技能训练课`, `军事理论课`等部分课程, 还可免修`课外研修课`和`两门通识选修课`. 

    符合学校转专业条件的, 按相关规定可以申请转入有接收计划的专业.

- 推荐免试研究生:

    学校所有学生均参加推免综合排名, 学校给在校期间参军入伍服兵役的学生适当加分奖励.

- 考研:

    退役3年内参加全国硕士研究生招生考试, 初试总分加10分, 同等条件下优先录取.

    也可参加`退役大学生士兵`专项硕士研究生招生计划.

- 读博与就业:

    硕士研究生入伍, 同等条件下优先推荐直升博士生.

    毕业生士兵退役后两年内回校, 按应届毕业生政策享受就业服务.
