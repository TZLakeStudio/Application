# 关系转接

## 1. 新生党, 团关系

新生团员的团组织关系须按照个人原所在学校相关要求, 在9月20日{ <span className="badge badge--success">倒计时{Math.ceil((new Date("2025-09-20") - new Date()) / (1000 * 60 * 60 * 24))}天</span> }前, 于`网上共青团•智慧团建`系统中发起转接申请, 由学院团委在核查团员档案后接收转入.

原所在学校尚未开通`网上共青团•智慧团建`系统的新生, 须在原就读学校开具纸质介绍信, 经学院团委核查团员档案后, 统一在`网上共青团•智慧团建`系统录入团员信息. 

新生党员组织关系须在全国党员管理信息系统中进行线上接转, 或持具有转接党员组织关系权限的党组织开具的党员组织关系纸质介绍信到所在学院办理组织关系转入手续.

## 2. 新生党员组织关系介绍信样式

湖南省及全国党员管理信息系统(简称"系统") 数据互通省份生源的新生党员由所在党组织通过系统进行网上接转, 不需要开具纸质介绍信.

系统中的党组织名称为: `中共湖南大学人工智能与机器人学院***支部委员会`(具体党支部名称请联系新生辅导员确认).

数据暂未实现系统互通省份生源的新生党员持有效的纸质党员组织关系介绍信到所在学院办理组织关系转入手续.纸质介绍信开头写: `中共湖南大学人工智能与机器人学院委员会`, 介绍信接收单位写`湖南大学人工智能与机器人学院学院`, 组织关系介绍信由本人随身携带, 注意不要放在新生人事档案中.

## 3.新生纸质档案转递

新生须按照相应省(自治区、直辖市)的有关规定办理纸质档案转递手续, 及时将档案转交至学院.
