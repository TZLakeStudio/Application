## 3.治安知识指南

### 3.1 注意防盗窃

1. 尽量少带现金, 大额现金最好存入银行.
2. 手机等费重物品要随身携带或锁进保险柜, 不要随意摆放.
3. 警惕陌生人进入宿舍以及任何形式的推销行为, 去上课, 自习和晚上就寝时关好寝室门窗, 不能留外人在寝室过夜.
4. 尽量在宿舍午休, 确需在教室午休的情况, 须将电脑, 手机及钱包等贵重物品妥善保管.
5. 学校不鼓动在校区(含学生园区)内使用电动车, 校内尽量选择步行或者共享单车等绿色出行方式, 确需购买电动车者请做好安装防盗锁, GPS定位等防盗措施, 且将车停放于指定区域. 人走落锁.
6. 宿舍钥匙, 校园卡妥善保管, 不随意借给他人, 更不要藏在门框等处.
7. 收取快递后, 及时销毁包装上的个人信息, 以免信息泄露被不法分子利用.
8. 取外卖时尽量及时到指定地点领取, 防止外卖被顺手牵羊.
   
### 3.2 发现盗窃案件后的应对措施

1. 及时报告, 第一时间联系学校保卫部门或者报警.
2. 保护现场, 不要触摸门窗, 抽屉等可能留有作案痕迹的地方.
3. 发现嫌疑人, 应立即报告学校保卫部门或报警.
4. 协助调查, 提供相关信息, 向工作人员详细陈述经过.
5. 尽快挂失.
   
### 3.3 注意防诈骗

1. 不要和陌生人搭话, 不要听信花言巧语, 不要贪图便宜.
2. 对以各种借口向你求助借钱借手机, 不要轻易相信, 让他们去找公安和保卫部门.
3. 不要把自己的手机和家里的电话号码随意告诉他人.
4. 不上违规网站, 不点陌生链接, 不轻信, 不转账, 谨防网络兼职, 冒充客服, 冒充家长, 买卖游戏账号等电信网络诈骗.
5. 警惕`校园贷`及衍生诈骗, 如有需要可以看学院官方消息.
6. 不要轻信中奖与福利信息, 这类诈骗可能会通过先交税费等方式才能领奖, 或通过链接窃取银行卡信息.
7. 部分骗子会通过冒充高年级学长学姐邀请新生参加活动, 向新生出售物品或者要求协助填写调查问卷等方式进行诈骗.
8. 在校园内或线上平台买卖二手物品(如手机、电脑)时, 要警惕低价诱惑.
   
### 3.4 发现犯罪疑点时应对方法

1. 观察判断, 用心识别: 发现犯罪疑点时, 要冷静观察, 仔细分析相关人员的行为, 言语等, 判断其是否存在违法犯罪的可能性.
2. 区分`疑点`与`确定犯罪`, 避免误判: 有些情况可能只是行为异常(如精神状态不佳者徘徊, 学生深夜找东西等), 不一定涉及犯罪.
3. 保护现场, 不随意触碰: 如果发现疑似犯罪现场(如门窗被撬, 有不明物品遗留等), 不要擅自进入或触碰现场物品, 避免破坏可能存在的指纹, 足迹, 物证等.
4. 巧妙周旋, 有效制止: 在确保自身安全的前提下, 可与可疑人员巧妙周旋, 避免直接冲突. 若有能力且时机合适, 可尝试有效制止其犯罪行为.
5. 注意自身信息保密: 报案或向相关部门反映情况后, 除非必要, 不要向无关人员透露自己的身份或举报行为, 尤其涉及有组织的可疑活动时, 防止被对方报复.
6. 及时报案. 如遇电信诈骗, 拨打报警电话 `96110`.
7. 特殊场景的针对性应对: 比如在公共交通工具上发现可疑人员, 可悄悄告知司机或乘务员, 由其协助处理.
8. 提供线索, 配合调查: 报案后, 积极向执法人员提供自己所掌握的线索, 如可疑人员的体貌特征, 行为细节, 物品特征等.

**核心还是围绕`安全优先`和`有效协助`, 既不轻视潜在风险, 也不盲目行动, 通过理性判断和合理措施, 最大限度发挥自身作用的同时保障安全.**
