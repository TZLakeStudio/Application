# 官方微信公众号

## 1. 湖南大学官方微信公众号

包括`信息平台`和`服务平台`两部分. 新生可以通过信息平台获取最新校园资讯及公告信息，

通过服务平台可实现**校园卡充值, 校园缴费, 财务查询, 一卡通信息, 图书借阅, 新生指引, 办公电话查询, 流量监控, 门户密码修改等服务功能**.

![湖南大学公众号](/docs/start/报到须知/2-4-湖南大学公众号.png)

## 2. 湖南大学微生活

### 2.1 公众号

`湖南大学微生活`公众号由湖南大学党委学生工作部(处)运营，是集`活动信息发布`, `综合信息查询`和`微社区`等多功能为一体的学生校园生活一站式服务平台. 

公众号整合全校活动资讯, 提供新生专属`萌新宝典`. 搭建`AI微微`. 提供校园生活全场景解答. 

此外, **绑定学号还可解锁`湖南大学微生活`小程序, 轻松玩转智慧校园. 关注它, 让你的湖大生活更省心!**

![微生活公众号](/docs/start/报到须知/2-4-微生活公众号.png)

### 2.2 小程序

**`湖南大学微生活`小程序是在校学子超高频使用的必备实用工具!** 提供一键查询课表, 成绩, 考试安排. 实时掌握校园卡账单, 空教室状态等功能. 覆盖学习与生活全场景, 助你高效开启湖大生活!

![微生活小程序](/docs/start/报到须知/2-4-微生活小程序.png)

## 3. 湖南大学教务处

`教务处公众号` 致力于为师生提供**便捷的服务和最新的教学活动信息: 课表, 成绩查询, 网上评教, 网上学习(课程中心), 岳麓讲坛, 求是讲堂资讯等等**.

大学学习生涯要经历的尽在其中, 欢迎关注湖南大学教务处微信公众号.

![教务处](/docs/start/报到须知/2-4-教务处.png)

## 4. 湖大青年

`湖大青年`是共青团湖南大学委员会打造的属于每一位湖大青年师生的文化品牌, 我们传播校园文化, 青春态度, 青年观念, 只为给你最棒的大学生活!

`湖大青年` 微信公众号是湖大校园潮流信息的集散地. 在这里, 团学组织, 社团活动, 校园文化, 周边热点, 深度专访, 榜样力量......

为你创造一整个团学宇宙, 给你最棒的大学生活!

![湖大青年](/docs/start/报到须知/2-4-湖大青年.png)

## 5. 湖南大学后勤保障

**`湖南大学后勤保障`微信公众号是湖南大学后勤保障服务平台**, 提供`后勤服务指南`, `信息查询`, `在线报修`, `建言献策`, `育人空间预约`等功能. 

欢迎各位新生关注, 及时获取校内后勤保障服务信息.

![后勤保障](/docs/start/报到须知/2-4-后勤保障.png)
