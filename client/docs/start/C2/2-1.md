# 新生报到

## 1. 报到须知
 
- `时间`: **2025年新生入学报到时间为2025年9月9日全天和9月10日上午**
- `流程`: 为减少排队聚集, 新生报到手续实行`先入寝后报到`服务. 新生直接到达`学生公寓门口`后, 出示`录取通知书`进入学生公寓园区, `凭录取通知书`进入楼栋. 学院新生辅导员在楼层为新生扫码, 确认报到, 生成电子报到单, 发放`2025级新生大礼包`和钥匙.
- `安全提示`: 新生报到途中请确保人身和财产安全, 谨防各类电信和网络诈骗.

## 2. 交通

为了您的出行方便, 建议提前在迎新系统确认住宿公寓, 通过导航查明路线, 避开交通高峰期.

同时, 湖南大学校内交通压力较大, 届时部分道路和路口实行机动车管制, 请家长和学生尽量乘坐火车(高铁), 飞机, 地铁, 公交等公共交通方式出行.

新生报到导航坐标:

### 2.1 湖南大学`天马`学生公寓

- **地铁站点**: 阜埠河路地铁站2号口, 3号出站(推荐)。
- **公交站点**: 阜埠河地铁站公交站, 八字墙公交站、科教兴村公交站。
- **周边停车区域**: 后湖路西段靠近清水路沿线, 湖南大学创新楼(生命医学交叉研究院)以及周边商业停车场.

### 2.2 湖南大学`德智`园学生公寓

- **地铁站点**: 阜埠河路地铁站2号口, 3号口出站(推荐).
- **公交站点**: 左家垅公交站.
- **周边停车区域**: 后湖路西侧靠近清水路沿线以及周边商业停车场.

## 3. 新生入学资格审查

**入学报到时, 学校对考生录取通知书, 居民身份证等材料与其纸质档案, 录取考生名册, 报到和录取数据等进行逐一核查. 并将现场采集的新生照片和高考报名照片, 居民身份证照片进行人像对比**.

审查合格的新生, 办理入学手续并予以注册学籍. 发现材料与本人实际情况不符的, 或者有其他违反国家招生考试规定情形的, 取消其入学资格. 

入学后3个月内, 学校对新生有关资格和证明材料进行复查, 对有关特殊类型录取新生开展入学专业复测. 复查确定为不合格的, 取消其入学资格或学籍. 

凡属弄虚作假, 徇私舞弊等方式冒名顶替入学以及其他违规录取的, 不论何时发现, 一经查实, 取消其入学资格或学籍. 情节严重的, 移交有关部门调查处理
