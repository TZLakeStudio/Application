# 本科生国(境)外交流学习

为了加快实现**高等教育国际化**的目标,鼓励更多的学生参与`国(境)外交流`, 开拓国际视野, 提升跨文化沟通和协作能力, 我校拓展了多种形式的**国(境)外交流学习项目**, 并设立`本科生出国(境)学习专项奖学金`, 支持**在籍学生**赴**世界一流大学**交流学习.
