# 官方微信公众号

## 1. 湖南大学毕业生就业

**`湖南大学毕业生就业`微信公众号是湖南大学就业指导服务平台**, 致力于让学生更详尽, 更快地了解最新的就业信息, 帮助湖大学子更好地就业.

## 2. 湖南大学国际合作与交流处(港澳台事务办公处)
