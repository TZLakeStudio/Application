## 赛事介绍

**RoboMaster 机甲大师高校系列赛(RMU, RoboMaster University Series)**, 作为全国大学生机器人大赛旗下赛事之一, 是专为全球科技爱好者打造的机器人竞技与学术交流平台. 致力于培养与吸纳具有工程思维的综合素质人才, 并将科技之美, 科技创新理念向公众广泛传递.

比赛以人才培养为核心, 积极传播青年工程师文化, 并打造全球顶级大学生机器人科技竞赛, 吸引了众多国内外优秀学校参与. 平台要求参赛队员走出课堂, 组成机甲战队, 自主研发制作多种机器人参与团队竞技. 他们将通过大赛获得宝贵的实践技能和战略思维, 在激烈的竞争中打造先进的智能机器人.

比赛侧重考察参赛队员对理工学科的综合应用与工程实践能力, 充分融合了`机器视觉`, `嵌入式系统设计`, `机械控制`, `惯性导航`, `人机交互`等众多机器人相关技术学科. 同时创新性地将电竞呈现方式与机器人竞技相结合, 使机器人对抗更加直观激烈, 吸引了众多的科技爱好者和社会公众的广泛关注.

## 战队介绍

湖南大学跃鹿战队正式成立于`2018年5月`, 由**湖南大学人工智能与机器人学院**(原机器人学院)牵头成立, 由人工智能与机器人学院, 电气与信息工程学院, 机械与运载工程学院, 信息科学与工程学院, 设计与艺术学院等各学院热爱机器人研发的本科生以及少数研究生组成.

### 战队近年获奖情况

- 2022 赛季, 由于过往的优异成绩, 湖南大学跃鹿战队正式晋级为甲级战队. 在超级对抗赛的比赛中获东部赛区二等奖, 全国三等奖. 运营组获评优秀宣传小组.
- 2023 赛季, 参加高校联盟赛(西南站), 3v3 对抗赛中取得了八强的好成绩. 步兵机器人获得 1v1, 3v3 机器人实战奖一等奖, 其中步兵 3v3 实战奖排名全国第二. 哨兵, 英雄获实战三等奖. 在超级对抗赛(南部赛区), 打平老牌强队华南理工大学, 华中科技大学, 小组赛积分并列第一, 机器人实战奖步兵机器人和工程机器人获实战奖一等奖. 其中步兵实战奖排名全国第一. 无人机, 英雄, 哨兵获实战奖三等奖. 团队研发的电控框架获优秀开源奖, 运营组被再度评选为优秀宣传小组.
- 2024 赛季, 跃鹿战队在湖北站, 福建站联盟赛均获得3V3八强, 1V1亚军的成绩, 并再次进入超级对抗赛, 区域二等奖, 全国三等奖. 步兵, 哨兵机器人单项一等奖.

### 竞赛表现

战队还支持队员参加其他赛事, 并在`中国国际大学生创新大赛`(原`互联网+`), `挑战杯`, `全国大学生电子设计竞赛`, `全国大学生机械创新设计大赛`, `全国大学生先进成图大赛`, `全国大学生数学建模竞赛`等赛事中取得省级以上奖项.

## 加入战队你将收获

### 专业技能提升

战队分为机械组, 电控组, 视觉组(算法组), 运营组. 每年比赛规则根据企业真实需求和科技发展前沿制定, 战队成员将经过培训和目标导向的个人学习, 积累实战经验, 通过实践加深对专业知识的理解, 通过历届队员的经验总结, 助力成长. 并通过和其他学校的优秀战队交流和开源资料, 助力你成为一名优秀的机器人青年工程师.

### 人脉收获

跃鹿战队已成立{(new Date().getFullYear() - 2018)}年, 战队总人数达数百人, 汇聚了全校在机器人及相关领域优秀的学生, 你将有机会学习他们的宝贵经验, 获得他们的指导. 在毕业生中已经走出了公司创始人, 前往知名院校深造, 前往知名企业就业的优秀队员, 战队将定期组织分享会, 邀请队员进行学习经验和职业发展分享. 战队还和其他战队保持良好的合作关系, 你将有机会参与交流赛, 技术经验交流, 结识全国各地的优秀青年工程师.

### 广阔职业选择

如果你能认真完成培训和备赛过程, 学习到真本领, 你将收获众多优秀科技企业(如大疆创新DJI, 影石Insta360)的优先招聘资格, 也将能迅速衔接企业工作需求.

### 组别介绍

:::tip 机械组

#### 你将参与:

- 机器人机械结构设计与建模
- 零部件受力分析与结构优化
- 3D打印, 非标零件设计, 激光切割等制造工作
- 整机装配, 调试与性能测试
- 参与机器人的机构方案设计与执行

#### 我们希望你:

- 对机器人, 机械设计与制造有浓厚兴趣
- 熟悉或愿意学习3D建模工具(如SolidWorks)
- 善于动手, 敢于尝试, 乐于在实验中解决问题
- 有责任心, 善于沟通, 具备良好的团队协作能力

#### 加入后你将学到:

- 机器人结构系统的设计与装配流程
- 工程建模与仿真分析能力(含力学分析与优化)
- 多种常用加工方式及工艺基础
- 从概念设计到实物落地的完整机械开发经验

:::

:::info 视觉组

#### 你将参与:

- 机器人视觉系统的整体设计
- 图像处理, 目标检测与识别算法实现
- 敌方装甲和能量机关的识别, 跟踪与预测算法开发
- 相机, 激光雷达等传感器数据的融合处理
- 雷达站对目标的识别, 定位与追踪算法开发
- 机器人自主导航系统开发
- 参与视觉任务部署与调试

#### 我们希望你:

- 对机器人, 人工智能, 图像处理等方向充满热情
- 热爱编程, 算法与探索, 喜欢研究技术背后的原理
- 具备一定的编程基础(如Python/C++) ~~不会也没关系~~
- 愿意主动学习并解决项目中遇到的挑战

#### 加入后你将学到:

- 计算机视觉基础与图像处理算法(如边缘检测, 颜色识别, 轮廓提取等)
- 目标检测/跟踪, 图像识别与神经网络在机器人中的应用
- 常用视觉开发工具链(OpenCV, YOLO, ROS, PCL等)
- 多传感器融合(视觉 + 激光雷达 + IMU)与系统实战调试能力
- 从算法原理到工程部署的完整落地过程

:::

:::warning 电控组

#### 你将参与:

- 机器人电控系统设计与调试
- PCB原理图与布线设计
- 嵌入式程序开发与硬件驱动
- 运动控制逻辑与通信协议实现
- 多模块联调与竞赛项目落地

#### 我们希望你:

- 对电子, 机器人, 编程感兴趣(有C语言基础更佳)
- 自主学习能力强, 肯付出时间钻研, 热爱动手尝试, 不怕调试与挑战
- 有责任感, 能与团队协作完成项目

#### 加入后你将学到：
- 电路设计与调试
- 嵌入式开发与RTOS应用(如FreeRTOS)
- 传感器, 电机, 通信等模块的控制
- 从硬件到软件的系统集成开发经验

:::

:::danger 运营组

运营组主要负责队伍的对外宣发, 寻找, 联络, 引入赞助商, 管理队伍官方平台. 旨在通过宣传手段, 提升队伍影响力, 以全面提升战队综合实力. 作为手握战队最新资料的第一人, 宣传内容产出的独家负责人, 是队伍不可或缺的存在.

运营组的经历将锻炼你的交际能力, 组织能力, 使你在产品经理等职位中更具竞争力.

#### 招新要求: 年级不限, 专业不限, 有时间和精力参与运营工作, 能够平衡学习和工作时间.

1. 需要有独立产出运营内容的能力(拥有以下任意技能: 有基础摄影, 修图能力. 有一定的文字功底和撰稿能力. 有微信公众号图文编辑排版和运营经验. 有一定绘画技能, 可以制作表情包, 动图, 简易动画视频等. 剪辑技能)
2. 具有较强沟通组织能力, 善于组织集体活动, 定期策划和组织团建, 经验交流等活动.

:::
