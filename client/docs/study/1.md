# 大物实验缺勤处理

___

当你因为种种原因忘记去做实验(一般指 `A2` )时, 你可以:

1. 马上联系老师, 说明情况, 并询问老师是否可以补做实验. 好点的老师给你记请假或给你机会补做, 坏点的老师记旷课(点名钟璨).

   (联系方式可由: `寻找老师官网`, `相关实验室门口`, `集市求助` 等渠道获得)

2. 如果老师同意补做实验, 那么恭喜你危机解除.
3. 如果老师不同意补做实验, 那么你只能接受记旷课的事实.

    大于`9学时`的旷课当挂科处理, `小于等于9学时`的旷课会为`0分`进入最终成绩加权计算. 

    如果你是保研选手, 前者意味着你失去保研资格, 后者你可以之后多选实验以拉高加权总量. 

    但学时有上限, 一般最后可以将满分补救成 `90` 左右, 最后成绩约为 `80` (老师打分均分在 `90` 左右).
